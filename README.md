# MCP DataBlind – Omni Gateway policy

Cryptographic field governance for APIs and AI agents. This custom policy for Anypoint Omni Gateway (Flex Gateway) protects sensitive fields in API and MCP server responses by sending them through the DataBlind service.

- **Set it up in your Anypoint account:** see the step-by-step [Setup Guide](docs/SETUP.md).
- **Release a new version:** run `./release.sh`.
